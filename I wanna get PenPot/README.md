# Penpot design kit

`medsos-au-kit.penpot` is the vector UI kit that mirrors the components in `ao3-workskin.css`.

## Import

1. Sign in at penpot.app (or your self-hosted Penpot).
2. In the Dashboard, open your project and choose **Import Penpot files**.
3. Select `medsos-au-kit.penpot`.

## Component specs to match

| Component | Spec |
| --- | --- |
| Twitter surfaces | Light `#ffffff`, Dim `#15202b`, Dark `#000000` |
| Twitter avatar | 48px circle, body 15px, post text 17px/24px |
| WhatsApp bubble | Radius 7.5px, in `#ffffff`, out `#d9fdd3`, header `#008069` |
| iMessage bubble | Radius 18px, sent `#007aff`, SMS `#34c759`, received `#e9e9eb` |
| Instagram bubble | Radius 22px, sent `#3797f0`, received `#efefef` |
